## 📥 Instalação e Uso

1. Faça o download da versão mais recente na aba de [Releases](https://github.com).
2. Mova o arquivo do plugin para a pasta correspondente no seu servidor (ex: `/oxide/plugins`).
3. O plugin será carregado automaticamente pelo servidor.

Para customizar o comportamento, edite o arquivo gerado na pasta de configurações:
```json
// Exemplo de configuração básica (mude conforme o seu plugin)
{
  "ConfiguracaoExemplo": true,
  "MensagemBoasVindas": "Bem-vindo ao servidor!"
```
